Персональный курс венгерского языка для подготовки к собеседованию в консульстве Венгрии по упрощённой натурализации. Этот файл — полная передача контекста: прочитав его, новая сессия может продолжить работу без истории переписки.

## 2. Что уже сделано

### Интерактивная страница `vengerskiy-do-prisyagi.html`
300 дней (старт 24.10.2026, без выходных, до 19.08.2027), 43 недели, 10 контрольных точек. Методика: ввод / извлечение / вывод, первые 2 недели — фонетика. Ежедневно ~70 мин: карточки 10, фразы RU→HU 10, текст дня с шэдоуингом 20, Duolingo 15, блок дня 15.

Вкладки: Сегодня, Неделя, Месяц, Весь план, Тренажёр (карточки в обе стороны, фразы с пропуском, текст дня, фонетика и минимальные пары, диктант, упражнения, острова консула, журнал ошибок, аудирование), Схемы и анимации (майндкарта недели, собиратель морфем, стрелки падежей, сортировка гармонии, отделение приставки, таблицы, инфографика), Видео, Ресурсы.

Возможности артефакта: `db` (прогресс, ошибки, карточки), `user`, `sample` (кнопки «Разобрать задание» и «Диалог с консулом» вызывают Claude).

Контент:
| Что | Где | Объём |
|---|---|---|
| Словарь по неделям | `words.py` | 1075 слов, по 25 на неделю |
| Клоуз-фразы | `phrases.py` (`PH`) | 430, по 10 на неделю |

## 3. Принятые решения

### Голоса
- Рассказчик: **ru-RU-DmitryNeural**, темп +8 %. (Svetlana отвергнута: «неживой, плоский»; из 19 голосов выбраны Dmitry и Rémy, по видео выбран Dmitry.)
- Диктор: **hu-HU-TamasNeural**, темп −15 %. Один голос на весь венгерский — и в роликах, и на странице.
- Слова в «кавычках» рассказчик читает отдельным куском без замедления, с паузами. Одиночные предлоги («в», «на») не произносить отдельно — Edge превращает «в» в мычание; говорить «в доме», «на столе».

### Назначение роликов
- Ролик **объясняет и показывает**, говорение вынесено в упражнения страницы. Каждая венгерская фраза звучит **один раз**, пауза ~1 с. Интерактив только «Проверьте себя» (русская фраза → 5 с → ответ).

### Визуальный стиль
- **Основа:** кинетическая типографика (проба C) + отдельные иллюстрированные предметы на кадре (не целые пейзажи).
- **Рисованные техники:** нравятся все 9 (`style/sheet/`), чередуем по урокам: гуашь, плоский вектор с зерном, ризограф, линогравюра, тушь с акцентом, акварель, бумажный коллаж, карандаши, вышивка матьо. Лучшее соотношение качество/цена: коллаж, плоский вектор, ризограф, линогравюра.
- **Цифровые техники** (`style/digital/`): основные — 9 дуотон-фотомонтаж, 1 шейп-анимация, 7 2,5D-камера с глубиной резкости. Элементами — 2 матовое стекло (карточки поверх сцены), 4 объёмная типографика (слово-заголовок урока), 6 глитч (короткие переходы, акцент на ошибке). Не используем: аврора, неон, пластилин.
- **3D (проба A) не используем:** ~22 мин рендера на 11 с без GPU.
- **Художники:** повтор стиля кодом интереснее оживления подлинников, допустимы оба. Билибин кодом 7/10, Айвазовский 5,5/10, Брюллов кодом не получается (3,5/10) — для него только подлинник. В оживлении движение должно быть выразительнее простого приближения.
- **Постоянный персонаж:** Кирилл (гуашевая кукла из пробы S: тёмные волосы, тёмно-зелёный свитер, джинсы, рюкзак). Слабые места: схематичное лицо, ноги без коленей, нет вида со спины.
- **Направления моушн-дизайна в пробе S** (9 штук): прорисовка тушью, гуашевый предмет + кинетическая типографика, бумажный коллаж, газетная вёрстка, схема-поток, анимированная карта (Natural Earth), переписка-мессенджер, проверка в стиле Apple, итоговый постер. Отзыв по конкретным сценам ещё не получен.

### Интерфейс страницы
- Убрать лишние служебные подписи («Контекст:», «Грамматика недели:», «Лексика:», «Duolingo:», «Вопрос консула:», «Последний разбор Claude», строку с именем голоса и т. п.) и коды дней вида M01-W01-D001.
- Майндкарта недели должна выглядеть как настоящая радиальная майндкарта, а не вложенный список.
- Медленный режим проигрывать тот же файл на скорости 0,75, а не голосом устройства. Ответы консула и тексты, которые Claude генерирует на ходу, Tamás озвучить не может — вопрос «голос устройства или без озвучки» не решён.

## 4. Правила для всех слайдов
Полный текст: `video/pravila-slaydov.md` (19 правил). Главное:
1. Рассказчик говорит связными фразами живого преподавателя, без телеграфных обрывков; рассказчик не произносит венгерских слов.
2. Заголовок слайда — обычная фраза («Представим обычный дом»), без «Образ: дом» и без пустых слайдов-заголовков.
3. Кадр заполнен осмысленно; сквозная сетка из колонок; связи показаны явно (перевод под словом, соединение, общий цвет).
4. Постоянные цвета значений: куда #2D6A4F, где #3B6E9B, откуда #9A6B1F; окончание всегда в цвете значения.
5. Венгерский — Source Serif 4 прямой полужирный; русский — Source Serif 4 курсив, примерно вдвое мельче.
6. Иллюстрации аккуратные и детальные. **Пиктограммы-квадратики со стрелками и точками больше не используем** (правило 17 в файле устарело) — вместо них рисованные предметы и персонаж.
7. Запрещено: номер урока в углу, декоративные черты, капслок с разрядкой, служебные ярлыки, эмодзи.
8. Вход элемента 0,6 с без отскока, сцена не короче 4 с.

Шаблон сценария: `video/scenario-template.md` (частично устарел: в нём ещё есть повторы для говорения). Фирменный стиль движения: `MOTION.md`.

## 8. Как запустить локально (Windows / PowerShell)

```powershell
git clone https://github.com/ivanqwerty35725-collab/- hungarian
cd hungarian\hungarian-course
```

Скрипты писались в облачном контейнере и ссылаются на путь
`/tmp/claude-0/-home-user--/26b0ee40-e351-58da-864e-84e1c80e1382/scratchpad/hu`. Замените его на путь к папке `hungarian-course` (в PowerShell):

```powershell
$old = '/tmp/claude-0/-home-user--/26b0ee40-e351-58da-864e-84e1c80e1382/scratchpad/hu'
$new = (Get-Location).Path -replace '\\','/'
Get-ChildItem -Recurse -File -Include *.py,*.js,*.mjs,*.html,*.sh,*.json,*.md |
  ForEach-Object { (Get-Content $_.FullName -Raw) -replace [regex]::Escape($old), $new | Set-Content $_.FullName -NoNewline }
```

Нужные программы: Python 3.11+, Node.js 22, ffmpeg, Git.

```powershell
pip install edge-tts piper-tts
npx playwright install chromium
npx skills add heygen-com/hyperframes --all
```

Не сохранено (пересоздаётся): кэш аудиофрагментов, веса нейросетей (Piper, Silero, Depth Anything, LaMa), `node_modules`, покадровые черновики. Для Edge TTS нужен интернет.

Пересборка:
- страница: `bash build.sh` (или выполнить `python gen3.py` и шаг вставки `plan.json` в `tpl3.html` вручную);
- озвучка: `python tts.py w01 … w43 t01 … t43 isl`;
- ролик 03: `cd build; python v03f.py`, затем в папке проекта `npx --yes hyperframes@0.8.185 render`.
